# Consolidated Findings Matrix

## Rating guide

Severity is a **provisional engineering triage**, not a claim that a vulnerability was demonstrated. “Potential” means the concern follows from a public design choice but its server-side behavior was not observable. Confidence describes confidence in the stated observation, not confidence that a vulnerability exists.

## Evidence limits

- No form submission or crafted request was made, so action request methods, wire content types, response codes, and server payload validation were not observed.
- The browser helper stopped because it could not establish the active Chrome URL; no DevTools network trace was obtained.
- Server source, database, authentication, production logs, and private candidate pages were outside this passive review.
- Public policy wording and visible form fields support a data-minimization discussion, not a legal compliance conclusion.
